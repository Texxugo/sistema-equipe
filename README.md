## Reflexão
O que é um repositório? - Lugar onde você guarda, organiza um projeto e controla as versões.
O que é um commit? - Registro de alteração feita num projeto, salvando uma versão especifica no repositorio.
O que é uma branch? - Versão paralela do projeto onde você pode fazer alterações sem afetar o código principal.
O que é um Pull Request? - É uma solicitação para revisar e juntar alteraçõpes de uma branch no projeto principal.
Por que usar controle de usuários? - Permite definir quem pode acessar e modificar o projeto, garantindo organização, segurança e evitando alterações indevidas.
